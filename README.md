# LeMatic Field Service — GitHub Pages (flat)

Upload these files to the **root** of the repo. Do not keep them inside a folder.

## Files
- index.html
- app.css
- app.js
- templates.js
- sw.js
- manifest.webmanifest
- qrcode.min.js
- exceljs.min.js
- jspdf.umd.min.js
- jspdf.plugin.autotable.min.js
- Punchlist-Template.xlsx
- timecard-template.xlsx
- icon-192.png / icon-512.png / icon-512-maskable.png / apple-touch-icon.png

## GitHub
1. Open the repo on a computer (Windows Chrome is fine).
2. Delete old copies of these filenames if they exist.
3. Upload / drag the files from this zip into the repo root.
4. Commit.
5. Pages → Deploy from branch → `/` (root).

## iPhone after deploy
Close the PWA from the app switcher, reopen it.
This build is cache **v25**. If you still see the old UI, wait a minute and reopen once more.

Do not upload index.standalone.html.
